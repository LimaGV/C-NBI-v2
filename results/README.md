# Resultados computacionais

~~~text
data → computation → results
~~~

Nunca results → data/raw. Saída de modelo, simulação ou algoritmo não é dado
bruto, mesmo em Excel/CSV. Cada execução relevante terá run_id explícito,
manifesto com SHA/versão/dirty, ambiente/lock, parâmetros, decisões, entradas e
hashes, comandos e saídas/hashes. Linha Excel não substitui identificador.

Saídas locais ignoradas por padrão; evidências pequenas só após revisão de
conteúdo, permissões e rastreabilidade. Nenhuma execução científica nesta fase.
