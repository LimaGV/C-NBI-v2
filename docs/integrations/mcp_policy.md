# Política de ferramentas

Usar a ferramenta simples suficiente. Não gerar contexto amplo sem necessidade.
Teste mínimo e somente leitura é aceitável quando a tarefa pede validação.

Zotero primeiro para literatura potencialmente existente. Nunca marcar
FULLTEXT_VERIFIED por metadados, resumo ou teste de conectividade.
Context7: resolver biblioteca e consultar por conceito; serve somente ao software.
Serena: símbolos, referências, dependências, impacto antes de editar ciência.
Se ausente, registrar e usar rg/análise AST focada.
Repomix: somente visão ampla, revisão arquitetural ou auditoria cruzada.
fd localiza arquivos; rg busca texto; ast-grep trata estruturas, sem alias sg.

OpenAI Developer Docs MCP é fonte oficial preferencial quando exposto;
na ausência, páginas oficiais com fallback registrado. Não chamar web de teste MCP.
Não depender de code-review ou codex_app por instrução do responsável.
Blender fora do escopo. cua_repl/node_repl somente se necessários.

Distinguir instalado, exposto, declarado, autorizado e testado.
Não exportar configurações sensíveis para comprovar disponibilidade.
Zotero e serviços externos só são modificados se a tarefa exigir e autorizar.
