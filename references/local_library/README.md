# Biblioteca local de documentos

Pode guardar localmente artigos, teses, dissertações, livros, apostilas e normas,
sem substituir o Zotero como biblioteca pessoal canônica.
Não copiar toda a biblioteca nem baixar documentos nesta fase.

Binários são ignorados por padrão, incluindo PDF, EPUB e DJVU, sem pressupor
permissão de envio por o repositório ser privado. Somente Markdown, BibTeX,
YAML, JSON e CSV de metadados são elegíveis por padrão, ainda sujeitos a revisão.
Não versionar texto integral protegido por trocar a extensão para Markdown/JSON.
Respeitar direitos, confidencialidade e permissões de cada fonte.

Registrar caminho local permitido, SHA-256, Zotero key, proveniência e status em
nota seletiva. Um arquivo local disponível não é FULLTEXT_VERIFIED por si só.
Nenhum documento real foi copiado ou enviado nesta fase.
