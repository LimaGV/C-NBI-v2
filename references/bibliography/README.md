# Bibliografia seletiva

library.bib começa vazio. Antes de adicionar:
1. Consultar Zotero por título, autor, DOI ou tópico.
2. Conferir metadados e registrar biblioteca, item key e citekey quando disponível.
3. Preencher somente campos confirmados.
4. Atualizar índice e notas.
5. Inspecionar texto integral antes de FULLTEXT_VERIFIED.

Não exportar a biblioteca inteira nem incluir anexos automaticamente.
BibTeX não comprova suporte de claims: vincular a passagens verificadas.
