# Snapshots — preservação computacional

Cópias autocontidas dos valores efetivamente utilizados, criadas somente quando
necessário por procedimento explícito. Não substituem raw e não são editadas
depois de criadas. Registrar SHA-256, origem, hashes das dependências, ferramenta,
versão, procedimento de materialização, responsável e validação.

Links externos devem ser resolvidos e valores conferidos no processo futuro,
com evidência de como foram calculados. Copiar caches não comprova correção.
Não existe geração automática de snapshot nesta fase.
